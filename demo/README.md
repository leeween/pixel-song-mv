# 成片展示

仓库提供 [《微光存档》原创可运行示例](../examples/minimal/README.md)，可生成音轨、预览和重新导出。下面两支既有成片保存在作者本地 `demo/` 中，供查看制作效果：

| 本地文件 | 时长 | 画幅 | 大小 |
|---|---|---|---|
| `Baby_MV_small.mp4` | 3:39 | 1920×1080 | 约 17.6 MiB |
| `我是真的愛上你_像素MV.mp4` | 5:03 | 1920×1080 | 约 21.0 MiB |

这两支视频中的歌曲、歌词与录音不属于代码 MIT 许可证的授权范围。尚未在仓库记录再分发许可，因此视频默认被 `.gitignore` 排除，不打进源码 ZIP；仓库下载者不会自动获得它们。

确认公开展示所需的素材许可后，可将成片上传到获准的平台或 GitHub Release，再在本页加入真实展示链接、歌曲与录音来源、授权范围。没有确定链接前不添加失效占位链接。不要因仓库开源而推定他人可以商用其中的音乐。
